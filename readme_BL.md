Сценарий 1: Исследователь находит ген в NCBI
Контекст: Мария, молекулярный биолог, изучает ген BRCA1 на NCBI.

Последовательность действий:

Мария открывает страницу гена в NCBI: https://www.ncbi.nlm.nih.gov/nuccore/NM_007294.4

Расширение автоматически определяет страницу и добавляет кнопку "PrimerDesigner" в шапку

Мария нажимает кнопку:

Расширение парсит последовательность гена (5000+ нуклеотидов)

Извлекает метаданные: accession number, organism, gene name

Сохраняет в локальное хранилище

Открывается popup с предзаполненной последовательностью

Мария настраивает параметры:

Tm: 60°C (оставляет по умолчанию)

GC: 50% (оставляет)

Длина праймера: 22 (оставляет)

Нажимает "Подобрать праймеры":

Если есть интернет (запрос на сервер):

Расширение отправляет последовательность на сервер

Сервер запускает Primer3 с полным анализом

Возвращает 10 лучших пар с детальными характеристиками

Если интернета нет:

Расширение использует локальный эвристический движок

Генерирует праймеры на основе правил

Помечает их как "Оффлайн режим (эвристика)"

Мария видит результаты:

Топ-5 пар праймеров с оценками A-F

Для пары #1 (оценка A):

Forward: 5'-AGCTAGCTAGCTAGCTAGCTAG-3' (Tm: 61.2°C, GC: 52%)

Reverse: 3'-TCGATCGATCGATCGATCGATC-5' (Tm: 60.8°C, GC: 48%)

Размер продукта: 245 п.н.

Предупреждения: "Нет GC-clamp на 3'-конце" (для пары #3)

Мария нажимает на пару #1:

Разворачивается детальная информация

Показаны все параметры: self-any, self-end, hairpin MFE

График температуры плавления

Рекомендации по оптимизации

Мария копирует праймеры:

Нажимает "📋 Fwd" - последовательность в буфере

Нажимает "📋 Rev" - вторая последовательность

Вставляет в свой лабораторный журнал

Мария сохраняет пару:

Нажимает "💾 Сохранить"

Вводит название: "BRCA1_exon10_primers"

Праймеры сохраняются в локальном хранилище

Через неделю, после эксперимента:

Мария открывает расширение

Переходит во вкладку "Сохраненные"

Находит сохраненную пару

Нажимает "📝 Отзыв"

Выбирает результат: "✅ Успешно"

Добавляет условия: Tm=60°C, полимераза=Taq

Эти данные сохраняются для будущего обучения ML

Сценарий 2: Лаборант в полевых условиях (оффлайн)
Контекст: Алексей работает в экспедиции, где нет интернета. Ему нужно быстро проверить праймеры для секвенирования.

Последовательность действий:

Алексей открывает расширение (работает даже без интернета)

Видит индикатор "Оффлайн (эвристика)"

Вставляет последовательность из полевого блокнота

Настраивает параметры под свои условия

Получает результаты через локальный эвристический движок

Видит пометку "⚡ Оффлайн режим"

Выбирает лучшую пару и копирует

Когда появляется интернет:

Расширение автоматически синхронизирует данные

Отправляет последовательность и выбранные праймеры на сервер

Получает подтверждение синхронизации

Все сохраненные данные становятся доступны в облаке
